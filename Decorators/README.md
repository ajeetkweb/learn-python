# Decorator ?

A decorator is a function that takes another function (or class) and extends/modifies its behavior without changing the original code directly.


@decorator_name
def my_function():
    pass


# Why decorators are useful
Decorators help reuse logic cleanly.

# Common Use Cases:

    1. Logging : Track function calls.
    2. Timing Execution: Measure performance.
    3. Authentication / Authorization
    4. Caching Results
