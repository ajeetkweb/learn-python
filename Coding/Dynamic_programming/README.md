## What is Dynamic programming ?

Key Idea of Dynamic Programming

    Instead of solving the same problem again and again:

    We compute it once and store it.

    Instead of recalculating results repeatedly, DP stores results of subproblems and reuses them.


## Two common DP approaches:

# Memoization (Top-Down)

    Use recursion + caching results.

## Tabulation (Bottom-Up)

    Build a table iteratively from smallest subproblems.
